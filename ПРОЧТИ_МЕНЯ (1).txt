ПРОЧТИ_МЕНЯ.txt
================

Если ты скачал из чата большой файл (90+ МБ) с именем workspace-... —
это выгрузка ВСЕГО рабочего окружения, а не проект.

Нужный тебе архив с кодом сайта — glamai-studio-v7.zip (~200 КБ).
Он лежит:
1) В самой этой папке (рядом с этим файлом) — просто перетащи его на Рабочий стол.
2) Ещё одна копия — в папке download.

Что изменилось в v7 (по результатам твоего теста: «приложение вообще в отказе»):

1. ГЛАВНОЕ — ИСПРАВЛЕН «ПОЛНЫЙ ОТКАЗ» ПРИЛОЖЕНИЯ. Причина найдена: файл доступа
   к ИИ (.z-ai-config) записывался только в /tmp — на Windows эта папка не
   работает, ИИ-ключ не находился и ЛЮБАЯ генерация падала. Теперь файл
   записывается в папку проекта (работает на Windows/macOS/Linux), а на Vercel —
   во временную папку. Проверено юнит-тестами (7/7) и живой генерацией.

2. САМОДИАГНОСТИКА — страница /api/health. Открой в браузере адрес своего сайта
   + /api/health — приложение само покажет, что не так (нет ключа, ключ-заглушка,
   лимит запросов). Вариант /api/health?ping=1 проверяет ещё и сам ключ реальным
   запросом к ИИ. Подробности — в README-DEPLOY-RU.md, раздел 5.1.

3. ПРЕДУПРЕЖДЕНИЕ НА САЙТЕ. Если ключ не настроен, при открытии страницы сверху
   сразу появляется жёлтый баннер с инструкцией — не нужно угадывать по ошибке
   после генерации.

4. ЗАЩИТА ОТ ОШИБКИ С ЗАПОЛНИТЕЛЕМ. Если в .env остался текст «вставьте_сюда_
   ваш_ключ» вместо настоящего ключа — приложение честно об этом скажет.

5. ПОНИЖЕН РАСХОД ЛИМИТОВ (из твоего теста v6: «слишком много запросов»).
   Одна генерация раньше тратила до 4 обращений к ИИ (генерация + аудит +
   возможный ретрай + второй аудит). Теперь QA-цикл можно отключить галкой
   «Быстрый режим (без проверки качества)» — 1 обращение вместо 4, лимит
   расходуется вчетверо медленнее.

Проверено: сборка без ошибок (и для архива тоже), 7/7 юнит-тестов конфига,
живой тест страницы самодиагностики /api/health. Сама генерация живьём сегодня
не прогонялась: у песочницы, где я собираю проект, ИИ-платформа до утра
закрыла квоту (ошибка 429 «too many requests» — это не баг приложения, у тебя
со своим ключом такого не будет). Пайплайн генерации не менялся с версии,
которую ты уже тестировал, — там всё осталось как было.

Как достать из workspace-файла:
1. Установи бесплатный 7-Zip: https://www.7-zip.org (кнопка Download, далее «Далее-Далее»)
2. Правый клик по файлу workspace-... → 7-Zip → «Открыть архив»
3. Если увидишь ещё один файл без расширения — открой и его (7-Zip сам поймёт)
4. Найди файл glamai-studio-v7.zip и перетащи его в удобное место
5. Правый клик по нему → «Извлечь всё» — появится папка с кодом сайта
   (папки src, public, prisma и файлы package.json, README-DEPLOY-RU.md и др.)

Как узнать, что скачалось ПРАВИЛЬНО:
- имя файла: glamai-studio-v7.zip
- размер: около 200 КБ (не 90 МБ!)

Дальше — по инструкции README-DEPLOY-RU.md внутри архива:
GitHub (через браузер) → Vercel → готовый сайт.
Если что-то не заведётся — первым делом открой /api/health и пришли, что он покажет.
