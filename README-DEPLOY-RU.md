# GlamAI Studio — AI-помощник визажиста

Веб-приложение для превью макияжа на фото клиента: загрузите портрет, соберите образ
на палитре (8 продуктов, оттенки, интенсивность, финиш) или загрузите референсное фото —
и ИИ перенесет макияж на ваше фото, **сохранив лицо**. Есть слайдер «до/после».

- **Next.js 16** (App Router) + TypeScript + Tailwind 4
- Основной движок — **ProxyAPI** (api.proxyapi.ru): модели-редакторы изображений
  принимают фото на входе и правят его — лицо клиента сохраняется. Оплата в рублях.
- Запасные движки: Яндекс (Yandex Cloud AI Studio) → Z.AI — переключаются автоматически,
  если основной не настроен.
- Интерфейс на русском, зелёная тема с кнопками морской волны, адаптив под мобильные.

## 1. Локальный запуск

```bash
bun install        # или npm install
bun run dev        # или npm run dev
```

Откройте http://localhost:3000

## 2. Деплой на Vercel

### Шаг 1. Загрузите код в GitHub

```bash
git init
git add .
git commit -m "GlamAI Studio"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/glamai-studio.git
git push -u origin main
```

### Шаг 2. Импортируйте проект в Vercel

1. https://vercel.com → **Add New → Project** → выберите репозиторий
2. Framework определится сам (Next.js), ничего менять не нужно
3. **Environment Variables** заполним на шаге 3 (можно и сразу, до первого Deploy)
4. Нажмите **Deploy** — сборка займёт 1–2 минуты

### Шаг 3. Подключите движок ProxyAPI (основной)

1. Зарегистрируйтесь на https://proxyapi.ru и пополните баланс в кабинете
   (одна примерка макияжа стоит ~1,5–3 ₽ на Seedream — 200 ₽ хватает на ~100 правок).
2. Кабинет → **«Ключи API»** → создайте ключ (начинается с `sk-`).
3. В Vercel: **Settings → Environment Variables** → добавьте **4 переменные**
   (для Production и Preview):

   | Имя                 | Значение                              |
   |---------------------|---------------------------------------|
   | `PROXY_API_KEY`     | ваш ключ `sk-…` — одной строкой, без пробелов |
   | `PROXY_BASE_URL`    | `https://api.proxyapi.ru/v1`          |
   | `PROXY_EDIT_MODEL`  | `bytedance-seed/seedream-5-0-flash`   |
   | `PROXY_VISION_MODEL`| `qwen/qwen3.8-omni-flash`             |

   - `PROXY_EDIT_MODEL` — модель-**редактор** изображений (принимает фото на входе).
     Дешёвый и быстрый вариант — Seedream; максимум точности лица —
     `google/gemini-nano-banana-2.1` (~10 ₽/правка). Точные имена и цены — в каталоге
     https://proxyapi.ru/models (каталог обновляется: если пришёл 404, значит имя
     модели изменилось — возьмите текущее из каталога).
   - `PROXY_VISION_MODEL` — разбор референса и QA-аудит (~0,05 ₽ за разбор).
4. **Deployments → последний деплой → Redeploy.** Переменные действуют только
   на новые сборки — без Redeploy ничего не включится.

### Шаг 4. Подключите базу подписок (Neon — бесплатный Postgres)

База хранит только: Telegram-имя мастера, тариф и счётчики генераций.
Фото клиентов НЕ сохраняются ни в базу, ни на диск.

1. Откройте https://neon.tech → **Sign Up** (можно через GitHub) →
   **Create project** (имя любое, регион ближайший).
2. На панели проекта найдите **«Connection string»** → выберите **pooled connection**
   → скопируйте строку вида
   `postgresql://user:pass@ep-xxx-pooler.region.aws.neon.tech/neondb?sslmode=require`
3. В Vercel: **Settings → Environment Variables** → добавьте:

   | Имя               | Значение                                      |
   |-------------------|-----------------------------------------------|
   | `DATABASE_URL`    | скопированная строка подключения (одной строкой) |

   Таблицы создадутся сами при первом входе пользователя — миграции не нужны.

### Шаг 5. Создайте Telegram-бота для входа

1. В Telegram откройте **@BotFather** → команда `/newbot` → придумайте имя
   (например, «GlamAI Studio») и username бота (например, `GlamAIStudioBot`).
2. BotFather пришлёт **токен** вида `123456789:AA...` — сохраните его.
3. Там же в BotFather: `/setdomain` → выберите своего бота → введите адрес
   вашего сайта на Vercel (например, `glamai-studio.vercel.app`, без `https://`).
   Без этого шага кнопка входа работать не будет — Telegram проверяет домен.
4. (Рекомендуется) Включите вход одним нажатием — Mini App: в BotFather
   отправьте `/setmenubutton` → выберите своего бота → отправьте адрес сайта
   (`https://glamai-studio.vercel.app`) → отправьте подпись кнопки:
   `Открыть студию`. В чате с ботом появится кнопка меню (внизу слева):
   студия открывается прямо внутри Telegram, и мастер входит автоматически —
   без кодов и SMS, сайт проверяет подпись initData. Кнопка виджета на сайте
   остаётся запасным вариантом для входа из обычного браузера.
5. Сгенерируйте два секрета — откройте любой из вариантов:
   - терминал: `openssl rand -hex 32`
   - или онлайн-генератор случайных строк (64 символа)
6. В Vercel: **Settings → Environment Variables** → добавьте:

   | Имя                       | Значение                                          |
   |---------------------------|---------------------------------------------------|
   | `TELEGRAM_BOT_TOKEN`      | токен от BotFather (одной строкой)                |
   | `TELEGRAM_BOT_USERNAME`   | имя бота без `@` (например, `GlamAIStudioBot`)    |
   | `AUTH_SECRET`             | первая случайная строка (секрет сессий)           |
   | `ADMIN_SECRET`            | придумайте пароль — вход в админку `/admin`       |
   | `OWNER_TG_USERNAME`       | ваш Telegram без `@` — сюда придут оплаты         |
   | `OWNER_MAX_LINK`          | (необязательно) ссылка на профиль в MAX — кнопка «Написать в MAX» в paywall |
   | `TRIAL_LIMIT`             | `5` (сколько генераций даём бесплатно)            |

7. **Deployments → Redeploy.**

### Шаг 6. Проверка

1. Откройте сайт — увидите экран входа с кнопкой **«Log in with Telegram»**.
   Войдите со своего аккаунта — попадёте в студию, в шапке появится плашка
   «Пробные: 5 из 5».
2. Проверьте главный путь входа — через бота: в Telegram откройте своего
   бота → кнопка меню **«Открыть студию»** (внизу слева от поля ввода) →
   студия откроется внутри Telegram, и вход произойдёт сам, без кодов.
3. Откройте `https://имя-проекта.vercel.app/api/health` — должно быть
   `"status": "ok"`, провайдер «Прокси-шлюз», все PROXY-переменные заданы.
4. Откройте `/api/health?ping=1` — проверит сам ключ: `"proxyPing": {"ok": true}`.
5. (Опционально) `/api/diag?diag=1` — контрольная правка тестового квадрата
   через `/images/edits` (~1–5 ₽). Если `editsTest` зелёный — правка фото точно
   работает. Внимание: `chatTest` у ProxyAPI может быть красным — это норма,
   chat-ответы картинок не возвращают; без параметра `diag=1` роут ничего не тратит.
6. Загрузите фото → «Создать образ» → слайдер «до/после». Счётчик в шапке
   и зелёная плашка сверху уменьшатся на 1. После 5-й генерации откроется
   окно тарифов.
7. Откройте `https://имя-проекта.vercel.app/admin` → введите `ADMIN_SECRET` →
   увидите себя в списке. Здесь же выдаёте подписки после оплаты (см. ниже).

### Запасные движки (необязательно)

Приложение автоматически выбирает движок: если заданы `PROXY_API_KEY` и
`PROXY_BASE_URL` — работает ProxyAPI; иначе Яндекс при заданных `YC_API_KEY` +
`YC_FOLDER_ID`; иначе Z.AI. Старые переменные `ZAI_*` / `YC_*` можно не удалять —
они не мешают и остаются запасом. У публичного API Z.AI правки фото нет: там
приложение строит фотореалистичный портрет по описанию внешности, лицо может
отличаться; у Яндекса правки нет тоже. Только ProxyAPI сохраняет лицо клиента.

## 3. Как продавать подписку (ручной режим)

Пока автоплатежи не подключены (ЮKassa — отдельным шагом), продажи идут вручную.

### 3.1. Покажите реквизиты в окне оплаты (5 минут, один раз)

ВАЖНО СНАЧАЛА: `OWNER_TG_USERNAME` — это **ваш ЛИЧНЫЙ Telegram** (например
`cwd2485`), без @. Название студии или имя бота не подходит: по кнопке
«Выбрать тариф» Telegram откроет чат с тем, кто указан в переменной, и
если такого аккаунта нет — увидит «Имя не найдено», а бот деньги принять
не может (он не владеет картой).

Чтобы клиент сразу видел, **куда и сколько** переводить, задайте публичные
реквизиты в Vercel: **Settings → Environment Variables →** добавьте
переменные (значения увидят клиенты — так и задумано, это не секреты):

| Переменная | Пример значения | Что делает |
|---|---|---|
| `PAYMENT_PHONE` | `+7 9XX XXX-XX-XX` | Телефон для перевода по СБП — клиент в СВОЁМ банке жмёт «Перевести по номеру телефона», вводит номер — всё, до 100 000 ₽/мес без комиссии |
| `PAYMENT_BANK` | `Сбер` | Банк получателя — клиент увидит, что деньги придут именно туда |
| `PAYMENT_CARD_NUMBER` | `2200 7007 1234 5678` | Номер карты с кнопкой «Копировать» (запасной способ) |
| `PAYMENT_CARD_OWNER` | `Иван И.` | Имя получателя |
| `PAYMENT_LINK` | ссылка из банка | Необязательно: кнопка «Оплатить по ссылке», если ваш банк умеет создавать такие ссылки |

**Для `PAYMENT_PHONE` (Сбер и любой банк):** 1) в приложении банка включите
«Разрешить входящие переводы по СБП» (в Сбере: Профиль → Настройки →
Платежи и переводы → СБП) — тот самый ползунок; 2) телефон должен быть
привязан к карте, куда приходят деньги; 3) при переводе банк плательщика
показывает имя получателя — клиент проверит, что платит вам.

**Про `PAYMENT_LINK`:** в обычном приложении Сбера (физлицо) ссылку
создать нельзя — это только в СберБизнесе для юрлиц. Если банк не умеет —
не страшно, просто не заполняйте эту переменную: СБП-перевод по телефону
закрывает задачу. Ссылки есть, например, в Т-Банке.

После сохранения нажмите **Redeploy**. В окне оплаты появится блок
«Как оплатить»: телефон СБП с кнопкой «Копировать» (или кнопка СБП-ссылки,
если задана), карта и шаги. Если реквизиты ещё не заданы — окно просто
предложит клиенту написать вам в чат за реквизитами, продажи не ломаются.

**QR-код для оплаты** появляется сам: в окне оплаты (на компьютере — сразу,
на телефоне — по кнопке «Показать QR-код») и в админке `/admin` с кнопкой
«Скачать PNG для печати». В QR зашита сначала `PAYMENT_LINK`, а если её нет —
`PAYMENT_PHONE`: мастер наводит камеру (с другого телефона или с компьютера)
— банк открывается или показывается номер для перевода. PNG удобно
распечатать и повесить в студии или отправить мастеру в чате.

#### Кнопка «Написать в MAX» (необязательно)

У клиентов без Telegram должен быть запасной путь. Если задать переменную
`OWNER_MAX_LINK` (ссылка на ваш профиль в российском мессенджере MAX),
в окне оплаты появится кнопка **«Написать в MAX»**. Как взять ссылку:
в приложении MAX откройте Профиль → «Ссылка на профиль» (вида
`https://max.ru/u/...` или `https://max.ru/имя`) и вставьте её в Vercel
в переменную `OWNER_MAX_LINK` → Redeploy. Не задана — кнопка просто
не показывается, всё остальное работает как раньше.

### 3.2. Сценарий продажи

1. Мастер доходит до paywall («Пробные образы закончились»), выбирает
   **«Выбрать Старт — 690 ₽»** или **«Выбрать Салон — 2 490 ₽»** —
   открывается ваш чат (OWNER_TG_USERNAME) с готовым текстом: какой
   тариф, цена, @username и ID клиента. Внутри Telegram чат откроется
   прямо в приложении; в обычном браузере на компьютере откроется
   Telegram Web, а текст заявки автоматически скопируется в буфер —
   вставьте его в чат (Ctrl+V). Так ссылки t.me не перехватываются
   сторонними клиентами вроде Unigram.
2. Клиент переводит сумму по реквизитам из окна оплаты и присылает
   скриншот чека.
3. Автоподстановка: как только клиент нажал «Выбрать тариф», в
   **ваш-сайт/admin** (вход по `ADMIN_SECRET`) вверху страницы появится
   блок **«Заявки на подписку»** — имя, @username, ID, тариф, время.
   Сверьте чек в чате и нажмите «Выдать · 30 дн. · 690 ₽» в строке
   заявки — подписка включена. Срок (7/30/90 дней) выбирается выше,
   цена пересчитывается сама. ID приходит из подписанной сессии
   Telegram — подкинуть заявку от чужого имени нельзя. Лишняя заявка
   убирается кнопкой «Скрыть».
4. Ручной путь (если заявка не долетела): в блоке «Выдать / продлить
   подписку» укажите @username или ID (они уже есть в сообщении
   клиента), тариф и срок → **Выдать**.
   ВНИМАНИЕ: в поле вводится только @username или ID мастера — НЕ сумма
   (цена считается сама и показана под кнопкой). Проще всего: нажмите
   на @username в строке мастера в таблице ниже — он подставится в поле.
   Если ввели что-то не то — админка честно ответит «Пользователь не
   найден», успех она показывает только при реальной выдаче.
   Под строкой показывается сумма к оплате: «Старт» 30 дней — 690 ₽,
   90 дней — 2 070 ₽ (= 3 мес × 690 ₽); «Салон» 90 дней — 7 470 ₽.
4. Мастеру ничего перезагружать не надо: следующий клик «Создать образ»
   уже пройдёт по подписке — плашка в шапке покажет «Старт · до 7 дек».
   Продление добавляет дни к текущему сроку; месячная квота при выдаче
   обнуляется.

**Где смотреть продление:** колонка «Подписка до» в таблице мастеров в
/admin и плашка «Старт · до …» в шапке студии у самого мастера.

В админке видно: кто и когда заходил, сколько генераций сделал, чья подписка
активна. Кнопка «Сбросить пробный лимит» даёт мастеру ещё 5 бесплатных,
а «Отключить подписку» возвращает его на пробный тариф.

### 3.3. Пробный платёж на себе (проверка воронки за 10 минут)

1. Задайте `OWNER_TG_USERNAME` (ваш личный Telegram!) и `PAYMENT_*` (3.1),
   затем Redeploy.
2. Откройте студию через кнопку бота → когда пробные закончатся (у вас
   уже закончились), нажмите **«Выбрать тариф»** — вы увидите окно ровно
   так, как его увидит клиент: тарифы, ваша карта, шаги.
3. Нажмите **«Выбрать Старт — 690 ₽»** — откроется чат с самим собой с
   готовым текстом заявки. Переведите 690 ₽ на свою карту (в подарок
   самому себе) — чек «пришёл».
4. Откройте **/admin** → поле пользователя: `@cwd2485` (или ваш ID) →
   тариф «Старт», срок «30 дней» → **Выдать**. Появится зелёная плашка
   «Подписка выдана ✅ — действует до …».
5. Вернитесь в студию — в шапке «Старт · до …», можно генерить дальше
   по квоте 60/мес. Проверили? Кнопка **«Отключить подписку»** в админке
   вернёт вас на пробный тариф — воронку можно прогонять хоть каждый день.

## 5. Частые вопросы

**Генерация возвращает ошибку 401** — прокси не принял ключ. Проверьте, что
`PROXY_API_KEY` вставлен одной строкой без пробелов и переносов, и после
сохранения сделан **Redeploy** (переменные применяются только к новым сборкам).

**Ошибка 403** — модель недоступна на вашем тарифе или пуст баланс аккаунта
прокси. Проверьте в кабинете ProxyAPI.

**Ошибка 404** — прокси не нашёл путь или модель. Проверьте `PROXY_BASE_URL`
(должен заканчиваться на `/v1`) и точное имя модели в `PROXY_EDIT_MODEL` /
`PROXY_VISION_MODEL` по каталогу https://proxyapi.ru/models — каталог
обновляется, старые имена моделей уходят.

**«На аккаунте прокси не хватает средств»** — пополните баланс в кабинете
ProxyAPI и повторите.

**Ошибка 429** — сработал лимит запросов на прокси. Подождите минуту и
попробуйте снова.

**Долгая генерация** — норма: 10–40 секунд. В референс-режиме после правки
фото работает QA-аудит (проверка оттенков, симметрии и сохранности лица), а
при замечаниях — один корректирующий повтор с выбором лучшего варианта,
поэтому изредка ожидание доходит до ~1,5 минут. Лимит функции задан 120 с
(у Vercel с Fluid compute на Hobby-плане доступно до 300 с) — полный цикл
проверки качества помещается с запасом.

**Фото клиентов** — изображения обрабатываются в памяти и никуда не сохраняются:
ни в базу, ни на диск сервера. В базе лежат только Telegram-имя мастера,
тариф и счётчики генераций.

**Сайт показывает экран входа с подсказкой про переменные** — не заданы
`TELEGRAM_BOT_USERNAME` / `TELEGRAM_BOT_TOKEN` / `AUTH_SECRET`. Заполните их
(разделы «Шаг 4» и «Шаг 5») и сделайте Redeploy.

**Кнопка Telegram не нажимается / «Bot domain is invalid»** — не выполнен
`/setdomain` в @BotFather: имя домена должно в точности совпадать с адресом
сайта на Vercel (без `https://`, без слэша на конце).

**Вход зависает: «Подтверждающее сообщение отправлено», а подтверждение в
Telegram не приходит** — капризы oauth-входа на стороне Telegram: сообщение
может приходить с опозданием и помечаться «незавершённой попыткой входа».
Самый надёжный путь — вход одним нажатием: настройте `/setmenubutton` в
BotFather (Шаг 5, пункт 4). Кнопка бота «Открыть студию» открывает студию
внутри Telegram, и вход проходит автоматически — без кодов, SMS и
подтверждений.

**Внутри Telegram студия не входит сама (крутится «Входим через Telegram…»)**
— посмотрите версию внизу карточки входа («GlamAI Studio · v…»). Если там не
последняя версия (см. ПРОЧТИ_МЕНЯ.txt) — свежая сборка ещё не загружена на
Vercel: загрузите файлы архива в GitHub и дождитесь Redeploy. Если версия
свежая — открывайте студию строго кнопкой бота «Открыть студию» (не по ссылке
в чате), а если экран показал текст ошибки — пришлите его для диагностики.

**Как узнать, какая сборка задеплоена** — внизу экрана входа написано
«GlamAI Studio · v…», либо откройте `/api/health` — поле `version`.

**Ошибка «База подписок недоступна»** — не задан или неверный `DATABASE_URL`.
Проверьте строку подключения Neon (нужна pooled, с `sslmode=require`) и сделайте
Redeploy.

**Мастер оплатил, но лимит не появился** — он должен войти на сайт хотя бы раз
до выдачи подписки (иначе в базе нет его записи). Либо выдайте по его Telegram ID
(узнать можно в админке после его входа). Выданная подписка видна ему после
обновления страницы.

**Как поменять число бесплатных генераций** — переменная `TRIAL_LIMIT` в Vercel
(по умолчанию 5) + Redeploy.
